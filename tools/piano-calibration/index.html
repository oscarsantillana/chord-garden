      What this test collects
      
This uses the same recogniser as practice, with all 14 colour chords as candidates. The selected keys only label what you intended to play; they do not influence the answer. Each listen lasts up to 15 seconds.

      
Frequency measurements and recognition results stay in memory in this tab. No audio recording, device identifiers, storage, or network upload is used. Save diagnostics downloads those measurements as JSON so a failed attempt can be replayed locally. Starting another listen replaces the previous attempt.
